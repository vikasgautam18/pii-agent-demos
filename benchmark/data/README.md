# Synthetic Workload

`messages.jsonl` is a deterministic, regeneratable corpus of synthetic
banking-chat messages used by the benchmark.

## Format

One JSON object per line:

```json
{"id": "msg-0001", "scenario": "unblock_card", "length_bucket": "short",
 "density_bucket": "med", "n_entities": 3, "text": "Hi I'm ..."}
```

| Field            | Meaning                                                |
| ---------------- | ------------------------------------------------------ |
| `id`             | Stable identifier, embedded in result CSVs.            |
| `scenario`       | `unblock_card`, `report_lost`, or `order_new`.         |
| `length_bucket`  | `short` (~1 sentence), `med` (~paragraph), `long` (~5 paragraphs). |
| `density_bucket` | `low`, `med`, `high` — number of PII entities.         |
| `n_entities`     | Approximate count of entities the regex/NER will hit.  |
| `text`           | The actual message body.                               |

## Synthetic-data conventions (no real PII)

All values are deliberately fake and follow public test-data conventions so
nothing in this file collides with real Indian PII:

* **Aadhaar** — uses the leading-zero pattern (e.g. `0001 2345 6789`),
  which UIDAI documents as invalid/reserved. Real Aadhaar numbers cannot
  start with `0` or `1`.
* **PAN** — uses sequence `ABCDE1234F` and variants. The fourth letter `D`
  marks an "Association of Persons" placeholder used in PAN test fixtures.
* **Card numbers** — only the public test set published by card networks
  (`4111 1111 1111 1111`, `5555 5555 5555 4444`, `3782 822463 10005`,
  `6011 1111 1111 1117`).
* **Phone** — `+91 99999 9XXXX` range, also a documented test prefix.
* **Email** — `@example.com` and `@contoso.com` domains.
* **Customer IDs** — random 9-digit numbers unrelated to any real CRM.
* **Names** — generic Indian and Western names from a fixed pool.

## Regenerating

The file is regenerated byte-identically from a fixed seed:

```bash
python -m pii_bench generate --seed 42 --out data/messages.jsonl
```

If you want a different size or distribution, override the bucket counts:

```bash
python -m pii_bench generate \
    --short 30 --med 30 --long 10 \
    --seed 42 --out data/messages.jsonl
```
